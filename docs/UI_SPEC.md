> **状态**：V1 交互与界面原型规范（已融合真实口述稿试跑结论）
> **最后更新**：2026-11-25
> **关联文档**：[PRD.md](c:/src/writing/docs/PRD.md) · [ARCHITECTURE.md](c:/src/writing/docs/ARCHITECTURE.md)

## 1. 视觉与交互设计原则

1. **Document-first（文章居中，对话退居右侧）**：作者的文字永远是舞台主角；AI 诊断和对话是冷静的旁白与编辑台，不喧宾夺主。
2. **纸感与低噪音**：米白/浅灰底色 + 高可读衬线/无衬线中文排版（大行高、舒适行宽），减少花哨动效和视觉干扰，适合长时间沉静改稿。
3. **显性边界与可控感**：
   - 原文永不可误改（带「原始口述 · 只读」标识）；
   - 任何清洗改动都能一键 `Revert`；
   - 每一轮主编反馈、每一版草稿改动（`v1 → v2`）都清晰留痕，随时可回溯对比。

#### 交互细节
- **右栏顶部「写作初衷」卡片（第二处入口）**：立项时留空的话，在这里看完现状脉络图后往往会突然想明白“我其实是冲着哪件事写的”，点 `[+ 补充]` 即可原地输入（或点击 `[编辑]` 修改），无需退回弹窗；
- 点击左栏任意高亮改动块，弹出紧贴的气泡条展示改动类型（同音错字 / 漏标点 / 术语一致 / 可选口水词）与 `Revert / 采纳` 按钮；
- 点击右栏脉络图中的任意节点（如「4. 第三点 · ⚠ 主题漂移」），左栏自动滚动并高亮对应段落范围；
- 右栏支持在正文里划选任意一句话，一键加入「承重句清单」；
- 点击「确认底稿并进入 Round 1 审稿」后，自动将当前状态冻结写入 `cleaned.md`、`clean-diff.json` 和 `drafts/v1.md`，并立即触发 Round 1 主编诊断。

#### 核心交互细节
1. **常驻「写作初衷」锚点条（第三处入口，改稿时始终抬头可见）**：
   - 固定展示在左栏编辑区正上方（最多占 1–2 行，避免干扰写作），写着写着跑偏时一眼就能对照初心；点击右侧 `[改]` 可直接原地编辑（若此前留空，则显示 `🎯 写作初衷：未填写 [+ 补充]`）；
   - **对话自动回填**：如果作者一开始没填，而是在右侧和主编聊天时才聊出了真正初衷（例如试跑中那样），在结算提交下一版时系统会自动提取并高亮提示「检测到新的写作初衷，是否同步更新到顶部锚点？」，一键确认即可回写。
2. **划词提问 & 诊断卡片引用**：
   - 在左栏正文划选一段文字，浮出「引用此段问主编」小按钮，点击后自动在右侧输入框挂上引用块；
   - 点击右侧诊断卡片的 `[针对讨论]` 或追问条目的 `[直接回]`，自动带入上下文锚点，省去重复解释。
3. **「保存并提交新版 v(N+1)」的结算弹窗（防止上下文膨胀的核心）**：
   - 当作者在左栏改完一轮、点击「保存并提交 v3」时：
     1. 系统快速计算 `v2 → v3` 的变动摘要，并用轻量模型从 Round 2 聊天记录中提炼出 **3–5 条本轮共识 / 已否决建议**，以及**本轮新浮现或更新的「写作初衷」**；
     2. 弹窗展示这些条目，作者可一键勾选/删改（2 秒确认）；
     3. 确认后：`Round 2` 标记为 `settled` 归档，新建 `drafts/v3.md` 与 `Round 3`，主编基于「`v3` + `v2→v3 Diff` + 累积共识 + 最新写作初衷」给出新一轮精炼复审，绝不重复唠叨已解决或已否决的问题。
4. **版本对比模式**：
   - 左栏顶部的 `[对比 v1→v2 Diff]` 可一键在编辑器内切换为只读 Diff 视图，让作者清楚看到自己这一轮到底大改了什么。

## 4. 关键状态与容错体验

- **流式输出与中断**：主编诊断、自由对话、合规审查均使用 SSE 流式呈现，支持中途点击「停止生成」与「重新生成」；
- **防丢稿机制**：左栏编辑区采用防抖自动保存（本地草稿即时写盘），即使刷新页面或重启服务，当前未提交的改动也不会丢失；
- **AI 越界兜底**：若模型偶发在正文审稿中输出了“建议改成下面这段：……”等疑似代写内容，后端/前端提供明确视觉提示或自动提醒重试，守住「不给范文」的系统铁律。
