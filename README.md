# Redpen

> 一套 **Local-first** 的个人语音写作与主编式改稿工作台。  
> **红笔只批注、追问、划重点，绝不替你代写。**

---

## 为什么做 Redpen

很多时候，我们在语音录入转文字里已经把核心想法说了出来，但口述稿天然散乱、逻辑跳跃、容易绕圈；回看时往往摸不准问题到底出在哪里。

如果直接把口述稿交给大模型「帮我整理润色成公众号文章」，通常会落入两个陷阱：
1. **滑向平庸中位数**：模型把你的节奏和锋芒磨平，产出流畅却无归属的“公摊语言 / 商品内容”；
2. **陷入认知负债**：文章看似写完了，但思考链路被 AI 的六十分初稿锁死，你并未真正把问题想透。

受王焕超《AI 写作是一种命运》启发，Redpen 遵循四条底层原则：

- **分工伦理**：AI 负责「索引、透视结构、指出漏洞、苏格拉底追问、守住合规出口」，执笔权 100% 归作者。
- **先划承重墙，再动工**：围绕「锋利判断 / 可追溯个人经验 / 连续立场演化」锚定 2–5 句承重句，再展开改稿。
- **刻意保留一点低效**：仅做极克制的同音错字与漏标点清洗，支持逐处 Revert，守住你的个人表达签名。
- **沉淀连续写作主体**：长期积累你的立场演进与真实经历，新文章审稿时自动对照，让“自我修正的裂隙”显形。

## 核心功能与五阶段工作流

```text
[1. 收件箱] ──▶ [2. 清洗与脉络透视] ──▶ [3. 双栏改稿与主编对话] ──▶ [4. 标题与合规双检] ──▶ [5. 定稿与立场归档]
```

1. **收件箱 · 口述碎片库（Inbox）**
   - 直接从 ima 等笔记工具复制粘贴口述稿，原始文本以**只读 Markdown** 永久留存。
   - 自动提取标签、摘要、潜在承重句与经历暗门；支持跨碎片**选题聚合提醒**与单条/合并立项。
   - 立项时支持填写 **「写作初衷 / 触发场景」**（并在后续各阶段常驻可见、随时可改）。

2. **轻度清洗（Git Diff）与现状脉络透视**
   - **原子补丁级清洗**：仅修正语音同音错字、漏标点、术语一致性与可选口水词；后端自带防偷改护栏，前端支持逐处 **Revert / 采纳**。
   - **现状脉络图**：忠实切分口述层次，标出边界模糊、主题漂移、视角跳切、前后脱节、重复绕圈等结构病灶，点击联动高亮正文。
   - **承重句锁定**：勾选或划选原文，锁定撑起整篇文章的核心骨架。

3. **双栏改稿与主编对话循环（核心体验）**
   - **左栏（Document-first）**：干净的 Markdown 编辑器，支持自动防抖保存、版本切换（`v1 / v2 / v3...`）、版本间 Diff、常驻「写作初衷」锚点条、划词引用问主编、可折叠参考抽屉。
   - **右栏（Round-based 主编 · 风格 A）**：冷静克制、直指要害、就事论事；按 Round 分节输出 5 维度结构化诊断与追问，支持流式自由辩论与动态认账转向。
   - **正文绝不给范文**：严格限定为指位置、析原因、提问题、给方向。
   - **跨轮共识继承**：每次提交新版草稿时，自动压缩本轮共识、作者否决项（下轮严禁重提）及对话中新浮现的写作初衷，连同 `vN → v(N+1)` Diff 带入下一轮，避免长对话失焦。

4. **标题共创 & 发布前双重合规隐私审查**
   - **标题共创**（系统唯一允许直接给出成品候选的环节）：围绕已锁定的承重句，生成多切入角度的公众号候选标题。
   - **双重合规与隐私关口**：
     - 平台发布合规：排查违法违规、公众号高风险敏感表述；
     - 个人/公司隐私：排查直接身份/数据泄露，以及通过“时间 + 细节”组合反推身份的隐性泄露风险；支持一键定位原文并改完复检。

5. **定稿归档 & 个人写作主体档案馆（Archive）**
   - 导出干净的公众号长文 `final.md`（一键复制 Markdown）。
   - 定稿时自动提炼本篇核心立场与真实经历，经作者确认写入本地 `vault/archive/`；若修正或推翻了历史立场，自动建立 `supersedes` 演化链条，并在未来写作 Round 1 时自动检索对照。

## 快速开始

### 环境要求
- Node.js >= 20（当前已在 Node v24 下验证）
- pnpm >= 10

### 安装与启动

```bash
# 1. 安装依赖
pnpm install

# 2. （可选）准备环境变量，或启动后直接在页面「设置」里填写
cp .env.example .env

# 3. 同时启动本地后端 API (3090) 与 Web 工作台 (5173)
pnpm dev
```

启动后访问：**http://localhost:5173**

### 配置大模型 API
支持 **DeepSeek 官方 API** 或任意 **OpenAI Chat Completions 兼容中转站**：
- 在工作台左下角进入 **「设置」**，填写 `Base URL`、`API Key` 与主力模型（可选单独配置轻量高速模型用于打标/清洗/共识压缩），点击 **「测试 API 连通性」** 即可开始使用。
- 配置保存在本地 `vault/config.local.yaml`（已加入 `.gitignore`，不会提交到 Git）。

## 本地数据目录（`vault/`）

Redpen 采用 **Local-first** 设计：你的所有思想资产全部以纯文本 Markdown + YAML 存放在本地 `vault/` 目录（默认 `./vault`，可在设置页修改路径），随时可用 Obsidian、VS Code 或任意文本编辑器打开与备份，不锁死任何软件。

```text
vault/
├── config.local.yaml               # 本地 API 与模型配置（gitignored）
├── inbox/                          # 原始口述碎片（正文只读留存）
├── articles/                       # 文章项目区（一篇一文件夹）
│   └── 2026-11-25-xxx/
│       ├── meta.yaml               # 写作初衷、锁定的承重句、标题候选与阶段状态
│       ├── raw.md                  # 原始合并底稿
│       ├── cleaned.md              # 经 Diff 确认/Revert 后的清洗底稿
│       ├── clean-diff.json         # 逐处清洗补丁与 Revert 状态
│       ├── map.md / map.json       # 现状脉络图
│       ├── drafts/v1.md, v2.md...  # 作者每一版手改草稿
│       ├── rounds/round-01.md...   # 主编诊断、讨论记录与轮次共识
│       ├── compliance.md           # 发布前双重合规与隐私审查报告
│       └── final.md                # 公众号长文定稿
└── archive/
    ├── stances/                    # 立场演进库（含 supersedes 修正链）
    └── experiences/                # 个人经历库
```

## 工程结构与开发命令

采用 pnpm monorepo 与核心引擎解耦架构，便于后续按需扩展 `dsh`（DeepSeek Harness）等工具型插件并共享同一套 `vault/`：

```text
packages/
├── core/       # 无头核心引擎（VaultStore / CleanDiff / Structure / Editor / Publish / Archive / LLM）
├── server/     # 本地 Hono HTTP + SSE 服务（默认 127.0.0.1:3090）
└── web/        # React + Vite + Tailwind 独立本地 Web 工作台（默认 localhost:5173）
docs/           # 完整设计文档
```

常用命令：

```bash
pnpm dev          # 并行启动 server + web 开发服务
pnpm typecheck    # 全仓 TypeScript 类型检查
pnpm test         # 运行核心引擎单元测试（Vitest）
pnpm build        # 全仓构建校验
```
